JobHunter

Estúdios para abordar diretamente, com candidatura espontânea, mesmo sem vaga aberta. Ficam separados das vagas e têm o próprio funil. Os que têm página de carreiras no Greenhouse, Lever, Ashby ou Workable são vigiados a cada busca: vaga nova aparece na aba Vagas.

Novo estúdio

Carregue aqui seus currículos, portfólios e cover letters. O app guarda uma cópia de cada arquivo, e é daqui que saem os anexos dos rascunhos. Marque um padrão por idioma: ele vem selecionado em cada candidatura e você troca quando quiser. Cover letter só entra quando você escolhe.

Gmail (só cria rascunhos, nunca envia)

Crie um "ID do cliente OAuth" do tipo App para computador no Google Cloud Console (grátis), ative a Gmail API e cole abaixo. Deixe o app em produção (sem verificação, uso pessoal) para o login não expirar em 7 dias.

Estúdios para monitorar

Um identificador por linha. O identificador é o trecho da URL da página de carreiras: boards.greenhouse.io/xxx, jobs.lever.co/xxx, jobs.ashbyhq.com/xxx, apply.workable.com/xxx.
